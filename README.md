## Mobile Tickets Ionic
Este projeto foi desenvolvido para avaliação da primeira unidade na disciplina de Desenvolvimento Para Dispositívos móveis e trata-se de um aplicativo para controle de atendimento em filas de um laboratório médico.

#### Funcionalidades
O app é capaz de criar novas senhas e apresentar o número de senhas totais criadas para cada grupo de senhas. Sendo eles:

- SG - Senha Geral
- SP - Senha Prioritária
- SE - Senha Exame

#### Ferramentas utilizadas
- Ionic 7.2.1
- Angular 20.3.22
- Node 22.22.2

#### Como Utilizar
- `npm install` para instalar dependencias
- `ionic serve` para rodar a aplicação
